# 示例

每个 `.py` 都能 `python examples/<name>.py` 直接跑。

| 文件 | 说明 |
|---|---|
| demo_basic.py | 最小路由 |
| demo_rule_decider.py | 规则决策 |
| demo_train_decider.py | 训练 NB / TF-IDF |
| demo_budget.py | 预算约束 |
| demo_cache.py | 路由缓存 |
| demo_custom_policy.py | 多级自定义策略 |
| demo_openai.py | 接真实 OpenAI 兼容模型 |
| demo_http_client.py | HTTP 客户端 |
| demo_semantic_cache.py | 语义缓存 |
| demo_ensemble.py | 集成决策 |
| demo_threshold.py | 置信度门控 |
| demo_metrics.py | 可观测指标 |
