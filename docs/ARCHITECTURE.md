# 架构

```
                     ┌────────────────────────────┐
   用户请求 ───────▶ │         gateway            │  HTTP / CLI / SDK
                     │  /v1/route /v1/decide      │
                     │  /v1/chat/completions      │
                     └──────────────┬─────────────┘
                                    │
                     ┌──────────────▼─────────────┐
                     │          cache             │  路由缓存 / 语义缓存
                     │   命中直接返回，不跑模型      │
                     └──────────────┬─────────────┘
                                    │
                     ┌──────────────▼─────────────┐
                     │        CascadeRouter       │  多级级联
                     │  tier0(decider) → tier1... │
                     └──────┬──────────────┬──────┘
                            │              │
              ┌─────────────▼───┐   ┌──────▼────────────┐
              │    deciders     │   │     adapters      │
              │ mock/rule/NB/   │   │ mock/openai/      │
              │ tfidf/llm/...   │   │ anthropic/local   │
              └─────────────────┘   └───────────────────┘
                            │
              ┌─────────────▼───┐
              │     budget      │   成本 / 延迟预算约束
              └─────────────────┘
```

## 模块

- **deciders**：决策模型，在封闭选项集上打分（不生成文本）。
- **router**：级联路由，按置信度门控决定升级还是采纳。
- **budget**：成本 / 延迟预算，约束升级。
- **cache**：路由缓存 + 语义缓存，命中即省。
- **adapters**：模型 provider，mock / openai / anthropic / local。
- **gateway**：零依赖 HTTP 服务 + OpenAI 兼容端点。
- **eval**：合成数据集 + 指标 + 技能扫掠基准。
- **policy / config**：声明式策略加载与校验。
- **metrics**：路由过程可观测指标。
