# 性能模型

设 decider 成本 c0、延迟 l0，reasoner 成本 c1、延迟 l1，升级率 e，则：

```
实际成本 = c0 + e * c1
基线成本 = c1（所有请求直接走 reasoner）
成本节省 = 1 - (c0 + e*c1) / c1
提速比   = l1 / (l0 + e*l1)
```

默认 c0=1、c1=100、l0=5ms、l1=200ms：

- e=0（全就地解决）：成本节省 99%、提速 40x；
- e=1（全升级）：多付了 decider 那 1%，基本无收益——所以「无脑加一层」是亏的，
  只有 decider 足够强（e 足够低）才划算。

这正是「分层路由不是白加一层，而是把足够强的决策模型下沉」的原因。
