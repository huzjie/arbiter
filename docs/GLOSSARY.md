# 术语表

- **Decider（决策模型）**：在封闭选项集上打分选路的模型，不生成文本。
- **Reasoner（推理模型）**：兜底的大模型，能力更强、成本更高。
- **Tier（层级）**：级联中的一层，含决策模型 + 成本/延迟 + 阈值。
- **Cascade（级联）**：从便宜层到贵层逐级升级的路由结构。
- **Confidence gate（置信度门控）**：top1 概率 < 阈值才升级的机制。
- **Escalation（升级）**：把请求交给更贵的层。
- **Cost saved（成本节省）**：相对「全走 reasoner」省下的比例。
- **Budget（预算）**：成本 / 延迟硬上限。
