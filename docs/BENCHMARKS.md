# 基准

`python -m arbiter bench` 对决策模型 skill 从 0 扫到 1，观察各指标：

```
| skill | 路由准确率 | 决策准确率 | 升级率 | 成本节省 | 提速 |
|-------|-----------|-----------|--------|---------|------|
| 0.0   | 1.000     | 0.075     | 1.000  | 0.000   | 0.98x|
| ...   | ...       | ...       | ...    | ...     | ...  |
| 0.83  | 0.875     | 0.675     | 0.575  | 0.415   | 1.67x|
| 1.0   | 1.000     | 1.000     | 0.000  | 0.990   | 40.00x|
```

## 怎么读

- **决策准确率**随 skill 单调上升（0→1），证明 mock 后端模拟正确。
- **升级率**随 skill 单调下降（1→0）：模型越强，越少升级。
- **成本节省**随 skill 单调上升（0→0.99）：模型越强，越能就地解决。
- **路由准确率**始终接近 1.0：低 skill 时靠 reasoner 兜底纠正。
- 在 skill≈0.83 处有轻微回落——这是「自信但错误」的请求越过了阈值，
  直观展示了置信度阈值的代价/收益权衡。

这就是分层决策路由的全部价值：**准确率靠兜底保住，成本靠下沉省出来**。
