# 设计决策

1. **零依赖纯 Python 内核**：决策、路由、缓存、HTTP 全部标准库实现，克隆即跑。
2. **确定性 mock 后端**：`skill` 参数单调趋 1，离线验证「训练→能力提升」完整链路。
3. **正确性与置信度分开建模**：mock 决策模型里「准不准」和「敢不敢拍板」是两件事，
   分别随 skill 单调变化，逼真地复现真实分类器的行为。
4. **基线 = 直接走 reasoner**：成本节省是相对「不用决策模型」算的，
   诚实暴露「决策模型不够强时反而多付一层」的边界。
5. **封闭选项集**：决策模型永远在给定选项内选，杜绝幻觉出选项之外的结果。
